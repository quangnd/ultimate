# Ideas

Things that came up while working with Ultimate, worth keeping but not decided yet: no go, no branch, no code.
Each file is one idea: what was asked, what was found, the options and picks, and risks. When it's time to act on
one, start a normal branch from it (or @ultimate for an assessment).

One file per idea, named after it (`claude-quota-fallback.md`, not a date or an id). Add a one-line status at the
top: `Status: idea` while parked, `Status: building (#<conversation>)` once a branch takes it on, `Status: done
(#<conversation>)` once it lands, `Status: dropped — <why>` if it's abandoned.
